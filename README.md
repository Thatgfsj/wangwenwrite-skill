# wangwenwrite-skill

男频系统流网文全流程创作助手，覆盖选题研判 → 系统设定 → 大纲撰写 → 章节创作 → 润色优化 → 发布适配六大环节，贴合 2024-2026 行业爆款趋势。不替代作者创意，专注解决「设定崩坏、爽点失衡、AI味儿重、趋势脱节」四大痛点。

## 功能亮点

- **开篇三行法则**：三种万能切入（绝境切入/认知颠覆/身份错位），前三行即抛冲突
- **三大爆款节奏公式**：扮猪吃虎打脸流 / 神豪异能崛起流 / 仙侠逆袭热血流
- **单章五步法**：矛盾→仇恨→出手→震惊→钩子，每章独立爽点单元
- **锁链式推进**：解决旧麻烦→引出新麻烦，防中期写崩
- **系统流三位一体**：系统-剧情-世界观拧成一股绳，避免核心爽点偏移
- **反AI味儿全流程**：句式重构 + 口语化注入 + Show Don't Tell 对照表 + 禁用词库 + 反AI三问
- **书名公式**：前4个字包含冲突/悬念，适配算法平台首日阅读量
- **平台差异化**：番茄（300字炸点）/ 起点（剧情铺垫）/ 飞卢（极快节奏）

## 使用方法

### 安装

将 `wangwenwrite/` 放入 Claude Code skills 目录：
- 项目级：`<project>/.claude/skills/`
- 全局级：`~/.claude/skills/`

### 触发方式

- **自动触发**：输入包含「系统流、男频、大纲、金手指、爽点、情绪值、躺平变强、因果计数器」等关键词 ≥2 个，且提及创作/撰写/优化需求
- **手动调用**：输入 `调用wangwenwrite` 或 `用wangwenwrite生成/优化[需求]`

### 调用示例

```
调用wangwenwrite，生成都市+情绪值系统开篇，主角3个反差标签，适配番茄
用wangwenwrite优化这段系统流章节的爽点密度和AI味儿
用wangwenwrite搭一个躺平变强系统的核心设定，要求反常识金手指
用wangwenwrite给末日签到文起书名，适配起点
```

## 输出质量标准

- 开篇三行即冲突，300 字有钩子，3 章内系统觉醒
- 每章结尾有钩子，每 3 章一小爽、每 10 章一绝境反转
- 全程通过反 AI 三问自检（能拍出来吗 / 真人会说吗 / 删掉影响吗）
- 系统设定含明确能力边界与代价，避免后期崩坏
