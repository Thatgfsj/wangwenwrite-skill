# wangwenwrite-skill

男频系统流网文全流程创作助手，覆盖选题研判、系统设定、大纲撰写、章节创作、润色优化、发布适配全环节，贴合 2024-2026 行业爆款趋势。

## 核心能力

| 环节 | 说明 |
|------|------|
| 黄金三章打造 | 开篇三行法则、300字定生死、信息差反转、致命钩子 |
| 核心设定搭建 | 系统/人设/世界观三位一体，支持情绪值/躺平变强/因果计数器 |
| 分层大纲撰写 | 开篇详纲 + 中期节点 + 后期反转，锁链式推进防中期写崩 |
| 节奏与爽点 | 单章五步法、10章叙事单元、三大爆款节奏公式 |
| 反AI味儿优化 | 句式重构、口语化注入、反AI三问自检、禁用词库 |
| 发布适配 | 书名公式、平台差异化策略（番茄/起点/七猫/飞卢） |

## 功能亮点

- **开篇三行法则**：前三行直抛冲突，拒绝一切铺垫
- **三大爆款公式**：扮猪吃虎打脸流 / 神豪异能崛起流 / 仙侠逆袭热血流
- **系统流核心法则**：三位一体、规则限制、交换感、主观视角
- **反AI味儿实战清单**：句式重构 + 口语化 + Show Don't Tell + 禁用词库
- **书名公式**：三大公式，前4个字包含冲突/悬念
- **平台差异化**：番茄重爽点密集、起点重剧情铺垫、飞卢重极快节奏

## 使用方法

### 安装

将 `wangwenwrite/` 放入 Claude Code skills 目录（项目下 `.claude/skills/` 或全局 `~/.claude/skills/`）。

### 触发

- **自动触发**：输入包含「系统流、男频、大纲、金手指、爽点、情绪值」等关键词且提及创作需求
- **手动调用**：`调用wangwenwrite` 或 `用wangwenwrite生成/优化[需求]`

### 示例

```
调用wangwenwrite，生成都市+情绪值系统开篇，主角3个反差标签
用wangwenwrite优化这段系统流章节的爽点密度
用wangwenwrite搭一个躺平变强系统的核心设定
用wangwenwrite给末日签到文起书名，适配番茄
```

## 输出质量

- 开篇三行即冲突，300 字有钩子，3 章内系统觉醒
- 每章结尾有钩子，每 10 章有绝境反转
- 强制通过反 AI 三问自检
