# 一、技能概述

为男频系统流网文创作者提供全流程辅助，覆盖选题→设定→大纲→章节→润色→发布六大环节。不替代作者创意，专注解决「设定崩坏、爽点失衡、AI味儿重、趋势脱节」四大痛点。

**适用场景：**新手搭建框架 / 资深突破瓶颈 / 应急日更爆更 / 内容润色优化
**能力边界：**仅男频系统流（含都市+系统、末日+系统等类型融合），不支持女频与非系统流，不生成违规内容

# 二、黄金三章铁律

> 黄金三章 = 立主角 + 抛冲突 + 给钩子。每章都是独立的爽点单元。

## 2.1 开篇三行法则（优先级最高）

前 3 行文字决定读者去留。拒绝环境描写、心理独白、世界铺陈，直接抛入**死亡/背叛/侮辱**等强冲突。

三种万能切入方式：

| 类型 | 写法 | 示例 |
|------|------|------|
| 绝境切入 | 生死/伦理绝境 | 「解剖刀划开尸体胃袋，我看见女儿的学生证」 |
| 认知颠覆 | 反常画面打破预期 | 「掀开隔离舱，妹妹手臂上长满冰蓝色鳞片」 |
| 身份错位 | 行动与身份撕裂 | 「重生第三次，我攥着给初恋下毒的保温杯」 |

## 2.2 第一章：300字定生死

**必须做的：**
- 主角登场——用「选择」而非「描述」立住人设（让主角在 A/B 选项中做决定）
- 金手指上线——前 500 字内系统绑定/触发，交代核心机制
- 当场小反击——第一章末尾就要有第一次小爽感释放
- 结尾留钩子——推门声/异响/意外发现/系统突然提示

**严格禁止：**写景 / 大段回忆 / 无意义对话 / 铺世界观说明书 / 开局强冲突大能对打

## 2.3 第二章：立人设 + 信息差

核心是制造「读者知情，反派不知」的信息差——读者知道主角有系统/底牌，看着反派嚣张，产生上帝视角快感。

- 用具体事件展示系统功能（不是说明书式介绍）
- 以主角与配角对话推进，在剧情中自然交代世界规则
- 信息差反转：读者比反派多知道一个关键事实

## 2.4 第三章：小高潮 + 致命钩子

- 第一章的冲突升级（被退婚→家族宣布剥夺继承权）
- 主角做出第一个不可逆选择
- 结尾甩出「小反转 + 大疑问」
- 结尾钩子四种类型：危机升级 / 秘密揭开 / 新目标出现 / 断在最痒处

## 2.5 节奏铁律

| 规则 | 标准 |
|------|------|
| 3章内系统觉醒 | 最迟第 3 章，超时读者流失 |
| 每章结尾有钩子 | 推门声/反转/信息只给一半/危险突然降临 |
| 章节篇幅 | 2000-3000 字，适配碎片化阅读 |

# 三、爽点密度与节奏控制

## 3.1 三大爆款节奏公式

**扮猪吃虎打脸流**（最通用）:
```
压迫 → 隐忍 → 掉马（身份揭露）→ 碾压 → 后悔
```

**神豪异能崛起流**:
```
被欺压 → 开挂变强 → 实力碾压 → 逆天改命
```

**仙侠逆袭热血流**:
```
被嘲讽 → 奇遇开挂 → 修炼变强 → 战力碾压 → 逆天改命
```

## 3.2 单章五步法

```
Step 1: 抛出矛盾，制造困境
Step 2: 拉高仇恨值，强化对立
Step 3: 主角出手，解决问题
Step 4: 全场震惊，侧面烘托（不是主角自夸，是旁人反应）
Step 5: 结尾留钩子，引下一章
```

## 3.3 爽点密度标准

```
3章一小爽（保持热度不降温）
10章一大爽（推向情绪高潮）
爽后短暂缓冲（积蓄下一次爆发的力量）
```

每 10 章构成一个完整叙事单元：**冲突 → 施压 → 反转 → 爽点 → 钩子**，循环往复。

## 3.4 锁链式推进法（防止中期写崩）

```
解决旧麻烦 → 引出新麻烦 → 设定新目标 → 为目标努力 → 达成目标 → 引出更大麻烦……
```

**实战示例：**打了李家少爷（小麻烦）→ 他哥在青云宗要废你（中麻烦）→ 新目标：三月内考入青云宗 → 打败他哥 → 发现背后是王长老（大麻烦）→ 年底宗门大比进前十……

# 四、系统流核心法则

## 4.1 三位一体原则

系统、剧情、世界观必须拧成一股绳。系统是什么 → 主角就用它做什么 → 世界就围绕它运转。一旦刻意弱化系统来凸显主角努力，全文核心爽点崩坏。

## 4.2 系统必须有规则和限制

- 冷却时间 / 消耗资源（积分/寿命/情绪值）
- 等级不够功能未解锁
- 副作用（系统坑主角，制造笑点/危机）
- 交换感：主角付出代价 → 系统给予奖励。纯躺赢属于分支流派，主流系统文必须有「交换感」

## 4.3 标准句式结构

```
展示系统功能 → 主角内心反馈 → 后续驱动 + 行为

示例：
「你得到了丧尸赠送的奶茶，生存点+5」
这样也有生存点吗？
宋承拍了拍女人的肩膀："以后奶茶每天一杯，记得换口味。"
```

## 4.4 主角主观视角不可跑偏

全程以主角视角展开（第三人称写法，第一人称视角）。写配角或环境时，所见所感皆带主角的主观色彩——这是区分「AI味儿」和「人味儿」的关键标记。

# 五、反AI味儿实战清单

## 5.1 句式重构法

- 长难句拆成 3-5 个短句，每句 15-25 字，多用句号
- 打破工整的段落，段落长短参差不齐
- 一段话里不要每句都是「主语+谓语+宾语」

## 5.2 口语化注入

- 「其实」「呢」「就是」「话说」——适度加入口语填充词
- 用「再唠唠」代替「其次」，用「说真的」代替「值得注意的是」
- 允许语法上的小跳跃，像朋友发消息

## 5.3 反AI三问自检（每段必过）

- ✦ **这能拍出来/画出来吗？**（检查是否足够具象，抽象概念替换为动作/画面）
- ✦ **这是真人会说出来的话吗？**（检查语言自然度）
- ✦ **去掉这句/这个词，影响核心意思吗？**（删除一切冗余修饰）

## 5.4 情绪表达：Show, Don't Tell

| 低级写法（❌ AI味儿） | 高级写法（✅ 人味儿） |
|----------------------|---------------------|
| 他很伤心 | 攥紧手、沉默低头、快速走开 |
| 他很霸气 | 全场安静、敌人后退、旁人不敢说话 |
| 他很愤怒 | 指节捏得发白、牙齿咬得咯吱响、眼眶充血 |
| 系统很强大 | 系统可通过情绪值兑换因果扭转权限，最高可回溯24小时 |
| 读者很爽 | 经理摔在地上的瞬间，办公室里响起压抑的憋笑声 |
| 主角眼神一冷，心中暗道 | 他耳朵发红，心里疯狂吐槽：「……」 |

情绪不靠形容词堆砌，靠**动作**与**旁人反应**侧面呈现。

## 5.5 禁用词库

- ❌ 「主角眼神一冷」「心中暗道」「系统冰冷的声音响起」等模板化套话
- ❌ 「非常」「极其」「显著地」「深入地」等空洞修饰词
- ❌ 「首先…其次…最后…」「综上所述」「值得注意的是」等 AI 腔过渡词
- ❌ 「让我们一起看看」「准备好了吗」「你有没有想过」等引导式开篇
- ❌ 破折号尽量少用（已被平台AI检测工具标记为高风险特征）

## 5.6 必要的细节清单 ✅

- 世界观的风俗习惯（节日/饮食/俚语）
- 人设的小动作/口头禅/特殊习惯
- 系统的独特交互方式（不是冰冷的文字提示，而是有性格的对话）
- 具象的时间/场景（「上周三早上」比「某天」更有实感）

# 六、书名公式

## 6.1 三大公式

| 公式 | 适用 | 示例 |
|------|------|------|
| 核心设定 + 身份/标签 | 通用 | 《我不是戏神》《我在精神病院学斩神》 |
| 金手指 + 冲突对象 + 爽感预期 | 番茄/七猫 | 《时停起手，邪神也得给我跪下！》 |
| 反常理/身份错位 + 悬念 | 番茄 | 《全宗都是舔狗，小师妹是真狗》 |

## 6.2 核心规则

**前 4 个字必须包含冲突/悬念/核心设定**，让读者在 0.1 秒内判断是否点击。书名是作品的第一道钩子——番茄等算法平台中，书名决定首日阅读量。

# 七、执行 SOP

**步骤1 — 需求解析：**提取关键词 → 匹配趋势方向 → 输出解析报告（核心任务 + 适配趋势 + 执行重点）

**步骤2 — 核心设定搭建：**
- 系统：来源 + 类型（优先情绪值/躺平变强/因果计数器）+ 性格 + 核心机制 + 能力边界 + 代价
- 人设：3 个反差标签 + 具体缺陷 + 核心驱动力
- 世界观：力量体系 + 细节设定 + 系统与世界的关系

**步骤3 — 大纲撰写：**开篇 3 章详纲 → 中期剧情节点 → 后期反转方向。标注每章钩子位置、每 10 章绝境反转点。

**步骤4 — 章节创作：**遵循开篇三行法则 + 单章五步法，控制爽点密度，融入情绪过山车，全程通过反 AI 三问自检。

**步骤5 — 润色优化：**爽点密度检查 → AI 化表述替换 → 逻辑连贯性校验 → 输出优化版 + 修改说明（标注趋势适配点）

**步骤6 — 发布适配：**书名建议 + 章节标题 + 每章钩子提炼 + 日更节奏建议（4000-6000 字/天）+ 平台调性适配

# 八、决策分支

| 用户状态 | 执行策略 |
|---------|---------|
| 仅需单一环节 | 跳过其他步骤，聚焦该环节深度优化 |
| 有现有内容 | 跳过设定/大纲步骤，直接润色优化 |
| 需求模糊 | 输出引导提问（「请补充系统类型和世界观方向」），不猜测执行 |
| 指定平台 | 按平台调性调整输出 |
| 新手首次创作 | 优先套用模板，降低上手门槛 |
| 资深作者优化 | 侧重趋势适配和反转设计，可跳过基础模板 |

# 九、输出规范与模板

## 9.1 格式要求

- 标准 Markdown，标题层级清晰
- 设定/大纲用列表或表格；章节用段落式，短句为主
- 趋势适配点、核心爽点加粗

## 9.2 核心模板

**系统设定：**
- 系统来源：（濒死觉醒/神秘物品绑定/神明赐予/意外绑定）
- 系统类型：（情绪值系统/躺平变强系统/因果计数器/签到变强系统）
- 系统性格：（毒舌吐槽/贱兮兮AI/高冷中立/坑人助力）
- 核心机制：（奖励+惩罚+代价，避免奖励廉价）
- 能力边界：（明确上限、冷却时间、资源消耗、解锁条件）

**开篇3章大纲：**

第1章（300字钩子 + 主角登场）：
- 黄金三行：强情绪钩子，立刻抛入绝境/认知颠覆/身份错位
- 主角出场：用「选择」立住人设，3 个反差标签
- 冲突铺垫：核心矛盾在第一章末尾成形
- 结尾钩子：系统绑定前兆 / 意外发现 / 推门声

第2章（系统觉醒 + 初始奖励）：
- 系统觉醒：明确节点，有性格的系统提示音
- 系统介绍：通过事件展示功能，拒绝说明书
- 初始奖励：反常识优先
- 小爽点释放 + 信息差反转
- 结尾钩子：支线/主线任务触发

第3章（首次任务 + 情绪反转）：
- 任务执行：贴合人设，融入系统交互
- 冲突升级：敌人反应、旁观者态度
- 爽点爆发：「全场震惊，侧面烘托」
- 结尾钩子：更大的主线任务 / 隐藏阴谋

**章节内容（单章五步法）：**
```
（黄金三行钩子 — 直接切入冲突/系统提示/情绪爆点）

（主体内容：系统交互 + 冲突推进 + 情绪铺垫，短句节奏）

（爽点释放 — 旁人反应侧面烘托，不用主角自夸）

（结尾钩子 — 新任务/反转/悬念/信息只给一半）
```

# 十、平台差异化策略

| 平台 | 节奏要求 | 书名风格 | 内容偏好 |
|------|---------|---------|---------|
| 番茄/七猫 | 读者耐心 ≤300 字，情绪炸点前置，开篇即绝境 | 直白爽点+人设，一看就懂主角要干什么 | 爽点密集、追读率高、单章独立爽感 |
| 起点 | 允许适度铺垫，但每段服务于人设/伏笔 | 2-4字短书名，立意先行 | 剧情铺垫充分、反转有深度、群像塑造 |
| 飞卢 | 极快节奏，一句话含环境+情绪+表情 | 脑洞感强、冲突直给 | 都市爽文、高概念、脑洞大开 |

# 十一、常见错误规避

- **系统设定崩坏**（前期只能签到，后期突然能掌控生死）→ 设定环节明确能力边界，每步检查逻辑连贯性
- **爽点失衡**（开篇无钩子、10章后系统才觉醒、只虐不爽）→ 严格遵循开篇三行法则 + 单章五步法
- **AI味儿过重**（模板套话、情绪空洞、修饰词泛滥）→ 逐条对照反AI味儿检查清单，每段过反AI三问
- **趋势脱节**（仍用传统打怪升级金手指）→ 优先使用情绪值/躺平变强/因果计数器等2026趋势设定
- **人设脸谱化**（主角完美无缺、反派纯恶人）→ 主角必有3个反差标签+缺陷，反派要有具体动机和可共情的弱点
- **开篇即崩**（写景/回忆/世界观说明书开头）→ 开篇三行直抛冲突，拒绝一切铺垫
